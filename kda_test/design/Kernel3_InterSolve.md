# Kernel 3 核函数设计文档: Inter Solve Fused

## 1. 概述

`chunk_kda_fwd_kernel_inter_solve_fused` 是 KDA（Kernelized Delta Attention）块内计算的关键融合内核。它在一个 CTA 内完成三项任务：

1. 计算非对角线 Aqk / Akk 子块（6 对 16x16 块）
2. 对 4 个对角线子块做前向替换（forward substitution），求每个对角块的逆
3. 通过链式矩阵乘法合并得到完整的块三对角矩阵逆（即 `Akk_inv`，64x64 矩阵的下三角逆）

可选融合：FUSE_DIAGONAL 模式下直接在 Phase 1 计算对角线块；FUSE_RECOMPUTE 模式下直接输出 w/u/kg 而不存储 Akk_inv。

---

## 2. 输入输出定义

| 参数 | 形状/维度 | 类型 | 方向 | 说明 |
|------|-----------|------|------|------|
| `q` | `[B, T, H, K]` | 与 k 同 dtype | 输入 | Query 张量，用于计算 Aqk |
| `k` | `[B, T, H, K]` | fp16/bf16 | 输入 | Key 张量 |
| `g` | `[B, T, H, K]` | fp32 | 输入 | 逐元素门控值 (gate cumsum)，用于注意力加权 |

| `Akkd` | `[B, T, H, BC]` | fp32 | 输入/输出 | 对角线 Akk 块缓冲区；FUSE_DIAGONAL 模式下写入，非融合模式下读取 |

| `scale` | 标量 | float | 输入 | 注意力缩放因子 |

| `w_out` | `[B, T, H, K]` | 与 k 同 dtype | 输出 | 中间量 w = A_inv @ (k * beta * exp2(gk))（仅 FUSE_RECOMPUTE） |
| `u_out` | `[B, T, H, V]` | 与 k 同 dtype | 输出 | 中间量 u = A_inv @ (v * beta)（仅 FUSE_RECOMPUTE） |

| `chunk_indices` | `[NT, 2]` | int32 | 输入 | chunk 到 (序列索引, chunk 索引) 的映射 |
| `T` | 标量 | int | 输入 | 序列长度（定长） |
| `H, K, V` | 常量 | int | 编译期常量 | 头数、头维度、值维度 |
| `BT, BC, BK, BV` | 常量 | int | 编译期常量 | 块大小：BT=64, BC=16, BK=32, BV=64 |
| `IS_VARLEN` | 常量 | bool | 编译期常量 | 是否变长序列 |
| `USE_SAFE_GATE` | 常量 | bool | 编译期常量 | 是否使用 safe_gate（对角线已预求逆） |
| `FUSE_RECOMPUTE` | 常量 | bool | 编译期常量 | 是否融合 w/u/kg 重计算 |
| `FUSE_DIAGONAL` | 常量 | bool | 编译期常量 | 是否融合对角线块计算 |

## 3. 分核并行策略

```
Grid 布局:
  Grid = (NT, B * H)

  维度 0 (i_t):  遍历所有 chunk，NT = ceil(T / BT)（变长时为 chunk_indices 长度）
  维度 1 (i_bh): 遍历所有 (batch, head) 对

每个 CTA 负责:
  - 一个 (chunk, head) 对
  - 处理该 chunk 内的 4 个子块（共 BT=64 个 token，BC=16 token/子块）
```

```
Grid 映射示意:

  i_bh ──►
  ┌─────────────────────────────────────┐
  │ CTA(0,0) │ CTA(0,1) │ ... │ CTA(0,B*H-1) │  ← chunk 0
  │ CTA(1,0) │ CTA(1,1) │ ... │ CTA(1,B*H-1) │  ← chunk 1
  │   ...    │   ...    │ ... │     ...      │
  │ CTA(NT-1,0) │ ... │ ... │ CTA(NT-1,B*H-1) │ ← chunk NT-1
  └─────────────────────────────────────┘
                                          i_t
                                            │
                                            ▼

CTA 内资源:
  - num_warps = 1 (单 warp, 32 线程)
  - 寄存器: 18+ 个 [16, 16] float32 块 ≈ 18×256×4 = 18KB
```

## 4. 计算思路

### 4a. 块三对角矩阵结构

KDA 注意力中，每个 chunk（BT=64 token）内的 Akk 矩阵是一个 64x64 的下三角矩阵（因果掩码）。它被划分为 4x4 个 16x16 的子块（BC=16）：

```
Akk (64×64) = 4×4 子块, 每个子块 16×16

          col0    col1    col2    col3
         (0-15)  (16-31) (32-47) (48-63)
    ┌─────────────────────────────────────┐
r0  │  D0      │        │        │        │   子块 0 的 token 范围: [0,  15]
    │ [16×16]  │   0    │   0    │   0    │
    ├──────────┼────────┼────────┼────────┤
r1  │  Akk_10  │  D1    │        │        │   子块 1 的 token 范围: [16, 31]
    │ [16×16]  │[16×16] │   0    │   0    │
    ├──────────┼────────┼────────┼────────┤
r2  │  Akk_20  │ Akk_21 │  D2    │        │   子块 2 的 token 范围: [32, 47]
    │ [16×16]  │[16×16] │[16×16] │   0    │
    ├──────────┼────────┼────────┼────────┤
r3  │  Akk_30  │ Akk_31 │ Akk_32 │  D3    │   子块 3 的 token 范围: [48, 63]
    │ [16×16]  │[16×16] │[16×16] │[16×16] │
    └─────────────────────────────────────┘

图例:
  D0, D1, D2, D3    — 对角线子块 (16×16 下三角矩阵)
  Akk_ij (i>j)      — 非对角线下三角子块 (16×16 全矩阵)
  0                  — 零矩阵 (因果掩码, 上三角区域)
```

每个子块的计算公式：

```
Akk_ij = (K_i * exp2(G_i - GN_i)) @ (K_j * exp2(GN_i - G_j))^T * beta_j
Aqk_ij = (Q_i * exp2(G_i - GN_i)) @ (K_j * exp2(GN_i - G_j))^T * scale

其中:
  - i, j 为子块索引 (0-3), i > j
  - K_i: 子块 i 的 key [BC, K]
  - Q_i: 子块 i 的 query [BC, K]
  - G_i: 子块 i 的门控值 [BC, K]
  - GN_i: 子块 i 的归一化参考点 (此处为子块内最后一个 token 的门控值) [K]
  - beta_j: 子块 j 的逐 token 系数 [BC]
```

### 4b. Phase 1: 计算非对角线块

Phase 1 在一个 K 维度的循环中完成（BK=32，每次处理 32 个 K 维度的列）：

```
┌──────────────────────────────────────────────────────────────────┐
│ Phase 1: 循环 for i_k in range(ceil(K / BK))                    │
│                                                                  │
│  每次迭代加载:                                                    │
│    k0, g0  ← 子块 0 的 key 和 gate [BC, BK]                     │
│    (k1,g1,q1), (k2,g2,q2), (k3,g3,q3)  ← 根据有效范围加载        │
│                                                                  │
│  以子块对 (1,0) 为例:                                            │
│  ┌─────────────────────────────────────────┐                    │
│  │  b_gn1 = g[子块1的参考token, :]  [BK]    │                    │
│  │  b_gqn = exp2(g1 - gn1)         [BC,BK] │                    │
│  │  b_kgt = (k0 * exp2(gn1 - g0))^T [BK,BC]│                   │
│  │                                         │                    │
│  │  Aqk_10 += (q1 * b_gqn) @ b_kgt         │                    │
│  │  Akk_10 += (k1 * b_gqn) @ b_kgt         │                    │
│  └─────────────────────────────────────────┘                    │
│                                                                  │
│  计算的 6 对非对角线块:                                          │
│                                                                  │
│    (row, col)    有效条件      累积到寄存器                      │
│    ─────────────────────────────────────────                     │
│    (1, 0)       i_tc1 < T      b_Aqk10, b_Akk10                 │
│    (2, 0)       i_tc2 < T      b_Aqk20, b_Akk20                 │
│    (2, 1)       i_tc2 < T      b_Aqk21, b_Akk21                 │
│    (3, 0)       i_tc3 < T      b_Aqk30, b_Akk30                 │
│    (3, 1)       i_tc3 < T      b_Aqk31, b_Akk31                 │
│    (3, 2)       i_tc3 < T      b_Aqk32, b_Akk32                 │
│                                                                  │
│  寄存器占用: 12 个 [16,16] float32 块                            │
│    = 12 × 16 × 16 × 4 bytes = 12,288 bytes ≈ 12KB              │
└──────────────────────────────────────────────────────────────────┘
```

K 维度循环内的计算依赖关系图（以 (3,0), (3,1), (3,2) 三条链为例）：

```
迭代 i_k:
  load k0,g0 ──┬──► b_kgt(gn1-g0)^T ──► Aqk_10 += q1g @ b_kgt
               │                         Akk_10 += k1g @ b_kgt
               ├──► b_kgt(gn2-g0)^T ──► Aqk_20 += q2g @ b_kgt
               │                         Akk_20 += k2g @ b_kgt
               └──► b_kgt(gn3-g0)^T ──► Aqk_30 += q3g @ b_kgt
                                         Akk_30 += k3g @ b_kgt

  load k1,g1 ──┬──► b_kgt(gn2-g1)^T ──► Aqk_21 += q2g @ b_kgt
               │                         Akk_21 += k2g @ b_kgt
               └──► b_kgt(gn3-g1)^T ──► Aqk_31 += q3g @ b_kgt
                                         Akk_31 += k3g @ b_kgt

  load k2,g2 ─────► b_kgt(gn3-g2)^T ──► Aqk_32 += q3g @ b_kgt
                                         Akk_32 += k3g @ b_kgt
```

K 循环结束后，Aqk 块写入全局内存，Akk 块乘以 beta 系数留在寄存器：

```
Akk_ij = Akk_ij * beta_j[:, None]    (行广播 beta_j)
Aqk_ij 存储到全局内存 (带 scale)
```

### 4c. Phase 2: 对角线块的前向替换

前向替换用于求解下三角矩阵的逆。对于每个对角子块 `D`（16x16 下三角），使用逐行前向替换算法：

```
算法: 前向替换求下三角矩阵的逆

输入:  D = tril(D)  — 16×16 下三角矩阵 (存储了严格下三角，对角线隐含为1需要加回)
输出:  D_inv — D 的逆矩阵

第 1 步: 初始化
  A = -tril(D)         # 取负号，严格下三角部分
  for i in 2..15:      # 从第2行开始(跳过第0行=全零,第1行=仅(1,0)非零)
    a_row = A 的第 i 行  # [1, 16] 行向量
    a_row += sum(a_row[:, None] * A, axis=0)   # 矩阵行乘累加
    A[i, :] = a_row     # 更新第 i 行

第 2 步: 加回单位矩阵
  D_inv = A + I
```

可视化前向替换过程（以 4 个子块并行处理为例）：

```
┌──────────────────────────────────────────────────────────────────────┐
│ Phase 2: 前向替换 (并行处理 4 个 16×16 对角子块)                     │
│                                                                      │
│  b_Ai00 (子块 0)   b_Ai11 (子块 1)   b_Ai22 (子块 2)   b_Ai33 (子块 3)│
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐│
│  │ 1            │  │ 1            │  │ 1            │  │ 1            ││
│  │ x  1         │  │ x  1         │  │ x  1         │  │ x  1         ││
│  │ x  x  1      │  │ x  x  1      │  │ x  x  1      │  │ x  x  1      ││
│  │ ...     1    │  │ ...     1    │  │ ...     1    │  │ ...     1    ││
│  │ x  x ... x 1 │  │ x  x ... x 1 │  │ x  x ... x 1 │  │ x  x ... x 1 ││
│  └──────────────┘  └──────────────┘  └──────────────┘  └──────────────┘│
│                                                                      │
│  前向替换: 逐行从左到右累加                                           │
│                                                                      │
│  i=2:  A[2] = -(原始行 2) + A[2,0:1] @ A[0:1]                        │
│  i=3:  A[3] = -(原始行 3) + A[3,0:2] @ A[0:2]                        │
│  ...                                                                  │
│  i=15: A[15] = -(原始行 15) + A[15,0:14] @ A[0:14]                   │
│                                                                      │
│  最后: A += I (加上单位矩阵得到逆)                                    │
└──────────────────────────────────────────────────────────────────────┘
```

**对角线块来源说明：**

| 模式 | 对角线块来源 | 是否需要前向替换 |
|------|-------------|-----------------|
| `FUSE_DIAGONAL=True` | Phase 1 内联计算（b_Akk_d0~d3） | 是（刚算出的原始值） |
| `FUSE_DIAGONAL=False`, `USE_SAFE_GATE=True` | 从 Akkd 加载（已预求逆） | 否（跳过） |
| `FUSE_DIAGONAL=False`, `USE_SAFE_GATE=False` | 从 Akkd 加载（原始值） | 是 |

当 `FUSE_DIAGONAL=True` 时，对角线块存储到 Akkd 全局内存后通过 `tl.debug_barrier()` 同步，然后使用同一寄存器变量（如 `b_Ai00 = b_Akk_d0`）继续 Phase 2。

### 4d. Phase 3: 链式矩阵乘法合并逆矩阵

已知 4 个对角块的逆 `Ai_00, Ai_11, Ai_22, Ai_33` 和 6 个非对角线 Akk 块，通过链式矩阵乘法计算合并后的下三角逆矩阵：

```
公式推导 (块三对角矩阵求逆):

对于 4×4 块下三角矩阵 A:
  ┌               ┐
  │ A00   0   0  0│
  │ A10  A11  0  0│
  │ A20  A21 A22 0│
  │ A30  A31 A32 A33│
  └               ┘

其逆 A_inv 满足 A @ A_inv = I，即:
  第 0 行: A00 @ Ai_00 = I          → Ai_00 = A00^{-1}
  第 1 行: A10@Ai_00 + A11@Ai_10 = 0 → Ai_10 = -Ai_11 @ A10 @ Ai_00
            A11@Ai_11 = I            → Ai_11 = A11^{-1}
  第 2 行: A20@Ai_00 + A21@Ai_10 + A22@Ai_20 = 0
           → Ai_20 = -Ai_22 @ (A20@Ai_00 + A21@Ai_10)
            A21@Ai_11 + A22@Ai_21 = 0
           → Ai_21 = -Ai_22 @ A21 @ Ai_11
            A22@Ai_22 = I            → Ai_22 = A22^{-1}
  第 3 行: 同理...
```

```
┌──────────────────────────────────────────────────────────────────────┐
│ Phase 3: 链式矩阵乘法                                                │
│                                                                      │
│ 第 1 层 (直接邻居, 使用 2 个对角块):                                 │
│                                                                      │
│   Ai_10 = -Ai_11 @ Akk_10 @ Ai_00                                   │
│           ┌──────┐   ┌──────┐   ┌──────┐                            │
│           │16×16 │ @ │16×16 │ @ │16×16 │   = [16×16]                │
│           └──────┘   └──────┘   └──────┘                            │
│                                                                      │
│   Ai_21 = -Ai_22 @ Akk_21 @ Ai_11                                   │
│   Ai_32 = -Ai_33 @ Akk_32 @ Ai_22                                   │
│                                                                      │
│ 第 2 层 (距离为 2, 使用 3 个对角块):                                 │
│                                                                      │
│   Ai_20 = -Ai_22 @ (Akk_20@Ai_00 + Akk_21@Ai_10)                    │
│           ┌──────┐   ┌─────────────────────────┐                    │
│           │16×16 │ @ │   Akk_20@Ai_00           │                    │
│           │ Ai_22│   │ + Akk_21@Ai_10           │ ← [16×16]          │
│           └──────┘   └─────────────────────────┘                    │
│                                                                      │
│   Ai_31 = -Ai_33 @ (Akk_31@Ai_11 + Akk_32@Ai_21)                    │
│                                                                      │
│ 第 3 层 (距离为 3, 使用全部 4 个对角块):                             │
│                                                                      │
│   Ai_30 = -Ai_33 @ (Akk_30@Ai_00 + Akk_31@Ai_10 + Akk_32@Ai_20)     │
│           ┌──────┐   ┌───────────────────────────────────────┐      │
│           │16×16 │ @ │  第 0 行贡献  第 1 行贡献  第 2 行贡献 │      │
│           │ Ai_33│   │  +           +                        │      │
│           └──────┘   └───────────────────────────────────────┘      │
│                                                                      │
│ 精度: 使用 tf32 (SOLVE_TRIL_DOT_PRECISION) 以保证矩阵求逆精度       │
│                                                                      │
│ 计算顺序: 按依赖关系自底向上                                         │
│                                                                      │
│   第3层: Ai_30 ─────────────────────────────────────┐               │
│                                                      │               │
│   第2层: Ai_20 ───────────────┐    Ai_31 ──────┐    │               │
│                                │                │    │               │
│   第1层: Ai_10     Ai_21      │    Ai_32       │    │               │
│                                │                │    │               │
│          ├─依赖 Ai_00, Ai_11  │                │    │               │
│          │             ├─依赖 Ai_11, Ai_22     │    │               │
│          │             │              ├─依赖 Ai_22, Ai_33           │
│          │             │              │                              │
│          ▼             ▼              ▼                              │
│   源码中的计算顺序:                                                  │
│     1. Ai_10 = -Ai_11 @ Akk_10 @ Ai_00                             │

│     3. Ai_32 = -Ai_33 @ Akk_32 @ Ai_22                             │

│    Ai_10, Ai_20, Ai_21, Ai_30, Ai_31, Ai_32 (6 个非对角)            │
└──────────────────────────────────────────────────────────────────────┘
```

### 4e. FUSE_RECOMPUTE 融合模式

当 `FUSE_RECOMPUTE=True` 时，不存储 Akk_inv 到全局内存，而是直接利用寄存器中的逆矩阵计算 w、u、kg 并输出：

```
┌──────────────────────────────────────────────────────────────────────┐
│ FUSE_RECOMPUTE 模式: 直接计算 w, u, kg                               │
│                                                                      │
│  输入: 寄存器中的 Ai (Akk_inv 的 10 个 16×16 子块)                   │
│                                                                      │
│  1. u = A_inv @ (v * beta)                                          │
│     ┌─────────────────────────────────────────────────────────┐     │
│     │ 对每个 V 维度的 tile (BV=64):                            │     │
│     │                                                         │     │
│     │ b_u0 = Ai_00 @ (v0 * beta0)                             │     │
│     │ b_u1 = Ai_10 @ (v0 * beta0) + Ai_11 @ (v1 * beta1)     │     │
│     │ b_u2 = Ai_20 @ vb0 + Ai_21 @ vb1 + Ai_22 @ vb2         │     │
│     │ b_u3 = Ai_30 @ vb0 + Ai_31 @ vb1 + Ai_32 @ vb2         │     │
│     │       + Ai_33 @ (v3 * beta3)                            │     │
│     └─────────────────────────────────────────────────────────┘     │
│                                                                      │
│  2. w = A_inv @ (k * beta * exp2(gk))                               │
│     同 u 的计算模式，将 v 替换为 k * beta * exp2(gk)                 │
│     对每个 K 维度的 tile (BK=32):                                    │
│                                                                      │
│     b_kb_i = k_i * beta_i * exp2(gk_i)   (逐子块)                   │
│     b_w0 = Ai_00 @ b_kb0                                            │
│     b_w1 = Ai_10 @ b_kb0 + Ai_11 @ b_kb1                           │
│     b_w2 = Ai_20 @ b_kb0 + Ai_21 @ b_kb1 + Ai_22 @ b_kb2           │
│     b_w3 = Ai_30 @ b_kb0 + Ai_31 @ b_kb1 + Ai_32 @ b_kb2           │
│           + Ai_33 @ b_kb3                                            │
│                                                                      │
│  3. kg = k * exp2(gn - gk)                                          │
│     直接逐元素计算，无需矩阵乘:                                      │
│                                                                      │
│     b_kg_i = k_i * exp2(gn_last - gk_i)   (i = 0,1,2,3)            │
│     其中 gn_last = chunk 内最后一个 token 的 gate                   │
│                                                                      │
│  输出: w_out, u_out, kg_out (Akk 输出分支被 dead-code 消除)         │
└──────────────────────────────────────────────────────────────────────┘
```

## 7. 设计要点总结

1. **单 warp 设计**：num_warps=1，利用 Triton 自动向量化，避免 warp 间同步开销。64 token 的块计算量适中，单 warp 的寄存器压力可控。

2. **寄存器密集型**：Phase 1 需要 12-20 个 16x16 float32 块（12KB-20KB），Phase 3 需要 10 个（10KB）。在现代 GPU 上（每 SM 有 256KB 寄存器文件），单 warp 有 32x256x4=32KB 寄存器空间，足够容纳。

3. **精度选择**：链式矩阵乘使用 `SOLVE_TRIL_DOT_PRECISION`（支持时设为 tf32），确保矩阵求逆链的数值精度。对角线前向替换在 fp32 中进行。

4. **融合策略**：三个可选标志位提供灵活的融合程度：
   - `FUSE_DIAGONAL`：省去单独的对角线 kernel，在与非对角线相同的 K 循环中内联计算
   - `FUSE_RECOMPUTE`：省去 Akk_inv 的存储/加载和单独的 recompute kernel，直接在 Phase 3 后计算 w、u、kg
   - `USE_SAFE_GATE`：当对角块已预求逆时跳过 Phase 2 的前向替换

5. **计算-访存融合**：最激进的全融合配置（FUSE_DIAGONAL + FUSE_RECOMPUTE）在一个 kernel 内完成：对角+非对角块计算、前向替换、链式逆合并、w/u/kg 输出，消除了所有中间结果的全局内存往返。
